# Artifact pages

This repository serves the public page of each research artifact presented at an event: a poster, a talk or a workshop contribution. Each page is published at `https://esther-poniatowski.github.io/<event>_<topic>_<type>/`, where the event is named by its month and acronym, for example [2026-08-ccn_mixture-input-encoding_poster](https://esther-poniatowski.github.io/2026-08-ccn_mixture-input-encoding_poster/).

Each folder belongs to one artifact. The project repository of that artifact holds its sources and copies them here with [Ekpempsis](https://github.com/esther-poniatowski/ekpempsis), so a folder is never edited in place. The root of the site holds no page.
